PAYDAY 2 — Трекер достижений
=============================

ЧТО ЭТО
Приложение показывает все 1342 достижения игры, разбитые по 77 хайстам.
Для каждого хайста считает минимальное число проходов и показывает, что можно
добить попутно — общие счётчики убийств, навыки, репутацию.

КАК ЗАПУСТИТЬ
1. Скачай файл  PAYDAY Tracker.exe
2. Запусти двойным кликом
3. Откроется отдельное окно. Ничего устанавливать не нужно.

Если Windows скажет «SmartScreen» — нажми «Подробнее» → «Выполнить в любом случае».
Это обычная реакция на программу без цифровой подписи.

ЧТОБЫ ЗАБРАТЬ СВОЙ ПРОГРЕСС
Нажми «Импорт прогресса» → вставь ссылку на свой профиль Steam вида
    https://steamcommunity.com/id/ТвойНик/
или
    https://steamcommunity.com/profiles/76561198093257608
Подойдёт и просто ник, и просто цифровой ID без ссылки.

Профиль должен быть открытым (по умолчанию у всех он открыт).

ЧТОБЫ СЛЕДИТЬ В РЕАЛЬНОМ ВРЕМЕНИ
Та же кнопка → «Автообновление». Приложение будет само раз в 3 минуты
проверять профиль и отмечать новые достижения, пока ты играешь.
Страницу закрывать не надо — всё обновится само.

Важно: Steam обновляет свою статистику с задержкой, поэтому новое достижение
появляется в трекере через 3–6 минут после получения. Мгновенно без мода в игру
это невозможно.

ГДЕ ЛЕЖАТ МОИ ДАННЫЕ
Рядом с .exe появится файл  progress.json  — это твои отметки.
Скопируй его, чтобы перенести прогресс на другой компьютер.
Удалишь — начнёшь с нуля (кнопка «Сбросить всё» делает то же самое).

ТРЕБОВАНИЯ
Windows 10/11. Интернет нужен только чтобы забрать прогресс из Steam.
Никаких установок, никаких прав администратора.
