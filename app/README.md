# PAYDAY 2 — Трекер достижений

Локальное приложение: показывает все 1342 достижения игры, группирует их по
81 хайсту, считает минимальное число проходов и ведёт твой прогресс.

## Запуск

Двойной клик по **`start.bat`** (Windows) или `start.sh` (macOS/Linux).

Приложение поднимет локальный сервер и само откроет браузер на
`http://127.0.0.1:8899`. Нужен только Python 3 (никаких библиотек).

Закрыть — `Ctrl+C` в окне, где запущено.

## Свой прогресс

Кнопка **«Импорт прогресса»** открывает панель:

* **Загрузить из Steam** — вставь ссылку на страницу достижений своего профиля:
  `https://steamcommunity.com/profiles/<твой_id>/stats/218620/achievements`
  Профиль должен быть публичным. Достаётся всё, что уже получено.
* **Из файла** — укажи путь к файлу со списком названий (по одному в строке)
  либо к JSON. Подойдёт выгрузка из любого стороннего трекера.
* **Проверить данные** — прогоняет самопроверку базы: сходится ли всё.
* **Сбросить всё и удалить файл** — чистит прогресс, чтобы загрузить заново.

Отметки можно и ставить вручную галочками — они сохраняются сразу.

Где лежат данные: `progress.json` рядом с `server.py`.

## Что внутри

**Левая колонка** — 81 хайст, сгруппированы по контрактору. У каждого видно,
сколько закрыто, и цифрой `N✦` — сколько проходов нужно минимум.

**Шапка** — название хайста и «кол-во проходов» крупно.

**Центр** — план проходов (какой заход что закрывает), затем достижения
выбранного хайста, потом остальные разновидности, потом общий список.

**Правая колонка** — маски и убийства этого хайста, и «независимые» достижения,
которые капают в любом заходе.

**Разновидности.** Есть два вида, и они ведут себя по-разному:
* *добыча* — у «Ограбления банка» это Деньги / Ячейки / Золото / Случайное.
  Набор достижений разный: на золоте ячейки не закрыть.
* *карта* — у «Транспорта» пять карт, у каждой своя лестница сложности.
* *день* — многоходовые контракты (Крысы, Поджигатель и другие): достижения
  «на 2 день» берутся, только если доиграл до второго дня.

## Минимум проходов

Считается автоматически. Сложности складываются: один заход на высшей берёт и
все нижние ступени. А вот несовместимые условия требуют отдельного захода —
например «все сумки через канализацию» и «все сумки через небесный крюк»
физически не совместимы. Точные по сложности достижения (без «или выше»)
тоже стоят своего прохода.

## Откуда данные

Достижения — из Steam Community (это собственные строки игры, все 1342).
Русские названия и условия — из раздела «Связанные достижения» на
`payday.fandom.com/ru`. Привязка к хайстам — оттуда же, там она указана
прямо, а не выведена из текста.

## Если что-то сломалось

`verify.py` проверяет базу: пустые описания, остатки шаблонов вики,
дубли, битые ссылки на id, попадания достижений сразу в несколько хайстов.
Запускается сам при старте, отчёт в `verify_report.txt`.
