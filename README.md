# PAYDAY 2 — Трекер достижений

Локальное приложение (Windows, один .exe без установки): все 1342 достижения
PAYDAY 2, разбитые по 77 хайстам, с планом минимального числа заходов и счётчиками
прогресса в стиле Steam.

## Что умеет

- **Маршрут заходов** — для каждого хайста считает минимум проходов и что закроется
  попутно (лестницы сложностей, общие счётчики, маски).
- **Импорт из Steam** — по ссылке на профиль, плюс автообновление раз в 3 минуты,
  пока играешь. Достижение получено — счётчик сам встаёт на 100 %.
- **Счётчики** — 121 достижение с числовой целью («убить 666», «собрать 20»):
  полоса прогресса, процент, автозачёт при достижении цели.
- **Проверка данных по вики** — `deepverify.py` заново качает все статьи хайстов
  и сверяет состав, русские названия и условия поле-в-поле.
- **Самообновление** — кнопка «Обновление» проверяет последний релиз GitHub,
  скачивает новый .exe, подменяет файл и перезапускает приложение.

## Запуск

Скачать `PAYDAY Tracker.exe` из раздела
[Releases](https://github.com/Fankor70/payday2-tracker/releases), запустить
двойным кликом. Установка не нужна. Windows 10/11.

## Сборка из исходников

```
python pipeline.py              # из корня репозитория НЕ запускать — см. ниже
```

Пайплайн собирает данные и страницу; пути в стадиях относительно папки НАД
репозиторием, поэтому:

```
cd ..
python payday/pipeline.py
cd payday/app
python -m PyInstaller --onefile --windowed --name "PAYDAY Tracker" --icon app.ico ^
    --add-data "ui.html;." --add-data "data;data" ^
    --hidden-import webview.platforms.edgechromium --hidden-import webview.platforms.winforms ^
    --hidden-import clr --collect-submodules webview --clean --noconfirm tracker_app.py
```

## Релиз

```
python make_release.py 1.0.2 --notes "что нового"
```

Скрипт сам: проставит версию, пересоберёт данные и .exe, закоммитит, запушит
тег и создаст релиз с приложенным .exe. Приложение у пользователей само предложит
обновление через кнопку «Обновление».

## Структура

```
pipeline.py            конвейер данных (порядок стадий критичен — см. комментарии)
deepverify.py          независимая пересверка с вики, запускается в любой момент
heuristics.py          словари хайстов/источников для разбора английских условий
days.py                разбивка многоходовых контрактов по дням
app/                   приложение: server.py (API+Updater), store.py (прогресс),
                       build_ui.py (страница), tracker_app.py (окно pywebview),
                       version.py (версия), data/ (датасет)
```

Данные: Steam (список и факты получения) + русская вики PAYDAY 2 Fandom
(названия, условия, привязка к хайстам). Steam не отдаёт промежуточный прогресс —
числа счётчиков ставятся вручную, факт получения подтягивается сам.
